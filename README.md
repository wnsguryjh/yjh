## 03 · AI-Native Workflow

> 도구가 아니라 워크플로입니다. 총무 업무 전 주기(기획 → 구매 → 계약 → 운영 → 보고)에 AI를 단계별로 통합해, 검토·기획·보고의 리드타임을 60% 이상 단축했습니다.

| Stage | 내용 | 도구 | 지표 |
|---|---|---|---|
| 01 · 검토와 작성 | 도급 계약서 리스크 검토, 보고서 초안, 사내 공지·기획안 초안을 LLM으로 일차 산출 후 실무 큐레이션 | ChatGPT · Claude | 문서 작성 리드타임 −60% |
| 02 · 시장 조사와 비딩 | 벤더별 단가·시장 동향을 비딩 전 30분 안에 정리, 협상 테이블에 데이터로 등장 | Perplexity · Grok | 2년간 누적 비용 절감 −65.7% |
| 03 · 트렌드와 기획 | 총무 트렌드·글로벌 스마트 오피스 사례를 Deep Research로 수집·요약 | Genspark · Perplexity | 리서치 자동화 루틴 |
| 04 · 시각화와 보고 | KPI·절감 실적·공간 활용률을 임원 보고용 슬라이드·인포그래픽으로 즉시 변환 | Gamma · Napkin · Claude Artifacts | 슬라이드 제작 속도 5× |
| 05 · 운영 자동화 | 사내 식당 수요 예측, 통근버스 노선 최적화 | 수요 예측 · 노선 최적화 | 구성원 경험과 비용 동시 개선 |
| 06 · 운영 모니터링 | 라이선스 현황·갱신 일정·절감 진행률을 실시간 추적하는 인터랙티브 대시보드 자체 제작 | Chart.js · HTML/JS · 시뮬레이터 | 실작품 2건 운영 중 |
